# Recorded product walkthrough

The final MP4 is an actual browser recording of the local application, with narration generated by the installed system voice. It uses synthetic sample data and visibly labeled deterministic analysis; it does not claim a live Gemini call.

1. **Introduce MarginGuard and Genztech.** The workflow is investigation, sensitivity analysis, and approval tied to evidence.
2. **Open the sample overview.** Revenue is up 4.3%; contribution margin is down 18.1%. Follow the accounting bridge.
3. **Inspect discount evidence.** Show source lines, original CSV row references, the calculation, and SQL.
4. **Challenge a false hypothesis.** Ask whether discounts decreased. Show the contradicted status and the four execution stages.
5. **Change the decision assumptions.** Increase maximum extra return cost from ₹4 to ₹20. The recommendation changes to current policy. Restore ₹4.
6. **Create and approve the memo.** Explicitly acknowledge assumptions. Show recorded approval and PDF export capability.
7. **Correct a cost.** Include a reason. Show version 2 and the old memo becoming stale.
8. **Load the quality challenge.** Inspect the duplicate-refund quarantine, then acknowledge it. Explain that hard errors require a corrected import.
9. **Close with verification and team.** 49 backend tests, three real browser journeys. Baleeshwar Palavadi, team Genztech.

Source narration: `scripts/demo-narration.json`. Recording automation: `web/record-demo.cjs`. The recorded file should be uploaded to a public/unlisted video page or a shareable Drive file, then tested in a signed-out browser. No video has been published by this repository.
